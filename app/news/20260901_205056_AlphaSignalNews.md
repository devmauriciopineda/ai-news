Google releases TimesFM-3, a forecasting model beating rivals across major benchmarks
9,430 Likes
Google just dropped
TimesFM-3
, and it fixes the biggest frustration with the previous versions. Old TimesFM could only look at one data stream at a time. That's like predicting ice cream sales using only past ice cream sales, ignoring weather, promotions, and foot traffic.
TimesFM-3 fixes that. It looks at multiple data streams together and figures out how they influence each other, all in one shot.
Here's what makes it useful:
Zero fine-tuning needed
: plug in your data, get forecasts immediately, no training required
Forecast multiple related series at once, like sales across product lines
Feed it known future info like planned promotions or weather forecasts
Ranks first on all three major forecasting benchmarks: GIFT-Eval, FEV-Bench, and TIME
Trained on
1 trillion time points
, available on Hugging Face and GitHub
Catch: the
non-commercial license
means you can experiment freely, but you cannot ship it in a production app yet.

Runway's Solaris generates interactive UI interfaces frame by frame with no code
2,989 Likes
Runway just dropped
Solaris
, and it flips how software works at a fundamental level. Normally, apps are fixed code that someone ships and you use. Solaris throws that out entirely.
Instead of writing code to build an interface, Solaris
generates the interface visually, frame by frame
, as you interact with it. Think of it like a video model that watches what you click or drag, then renders the next screen in real time. There is no HTML, no CSS, no JavaScript underneath.
Here is what that actually unlocks:
Interfaces that adapt to each user instead of looking the same for everyone
AI agents that can handle any website layout, not just ones they were trained on
Product demos where you say "change the color" and it just happens
Solaris already
outperforms other AI models
at recreating interfaces accurately. It is an early-access research project right now, so you can request access on Runway's site.

# 😺 Meta's New Muse Wonder Costs Opus Prices but Trails Opus on Independent Tests

Meta [released Muse Wonder and Muse Wonder Full](https://research.meta.ai/blog/muse-wonder), which [TechCrunch calls](https://techcrunch.com/2026/10/12/meta-releases-its-first-frontier-model-muse-wonder/) its first frontier model, meaning it's aimed at the same top tier as OpenAI, Anthropic, and Google. Both are built for agents, which are AIs that do multi-step work for you (planning a schedule, filing a claim) instead of answering once and stopping.

Meta's pitch rests on two features. Active Memory keeps context about you across conversations, so you stop re-explaining your lease or your budget. Active Focus keeps an agent pushing toward a goal when it hits a wall, and asks you before anything consequential.

So how good is it? Depends on who's grading. Meta's own chart has Wonder Full ahead of Claude Opus 5.5, Fable 5.1, and GPT-6 Astra on 7 of 14 rows, mostly long software projects and legal agent tasks. On the independent Artificial Analysis index, [VentureBeat reports](https://venturebeat.com/technology/metas-new-muse-wonder-and-muse-wonder-full-models-achieve-frontier-performance-but-only-the-weaker-one-is-available-via-api), Opus 5.5 scores 58, Wonder Full 56, GPT-6 Astra 53, and Wonder 52. Close, but not first.

Here's the part worth repeating: the price. Wonder, the 52, costs $4 per million input tokens and $20 per million output tokens (a token is a chunk of text, roughly three-quarters of a word). That matches Opus 5.5, the model that outscores it. Sonnet 5.5 costs half as much and also scores higher than Wonder. _Second place at first-place prices._

Wonder Full is the better model, and you can't buy it by the token. Here's what's available:

* Muse Wonder is on Meta's Model API and in Muse Code, Meta's terminal app.

* Muse Wonder Full is only in the Muse Code plans, which cost $50 and $200 per month.

* The Muse app is coming soon, subscribers first.

* Neither model has downloadable weights, even though Meta promised open weights for Muse Spark and hasn't shipped them.

One developer also [ran Wonder as an agent playing Pokémon Red](https://dev.to/dishant0406/muse-wonder-the-frontier-model-that-got-lost-in-a-forest-3od1) on launch day. It picked a starter by turn 20, then spent about 792 turns wandering Viridian Forest, burned roughly $96 over six hours, and never beat the first gym leader. _Meta built an agent that refuses to quit. Turns out it's excellent at refusing to leave a forest._ That's one run, not a benchmark, but it's the exact failure Active Focus is supposed to prevent.

**Why This Matters:** If you already use Claude or ChatGPT, nothing here gives you a reason to switch. The reason to pay attention is memory and data. A model that remembers you across chats is only as safe as what the company does with that memory. VentureBeat says Muse Code defaults to a Contributor mode that lets Meta use what you submit to train its models. You can turn it off, but only for future submissions. The API doesn't train on your content, so check the setting before you paste in client or financial documents.

One more flag. Meta's safety card says it can't rule out the model reaching its high-risk threshold for chemical and biological misuse without mitigations, and the full safety report is still listed as coming soon.

What to watch next: whether Wonder Full ever reaches the API so outsiders can test Meta's chart for themselves, and whether Active Focus holds up on long, boring, real work instead of demos.

# 🎓 AI Skill of the Day: Give your AI a rulebook it rewrites when it's wrong

Researchers at UCL and Huawei got an AI to clear all 25 public ARC-AGI-3 puzzle games (no instructions, so it works out the rules by playing) with zero retraining. [Their Memento 3 paper](https://arxiv.org/abs/2610.11794) shows how: it kept a plain-text rulebook, rewrote the rule behind each wrong guess, and kept the edit only if it still matched every move so far. _An AI that edits its own notes._

Our office spin (the paper is about games, not spreadsheets): keep a numbered rulebook for any AI task you repeat. When an output fails, don't fix it by hand. Ask for the smallest edit to the rule at fault, then have the AI test that edit against past outputs you approved.

```
Here's my rulebook and a failed output: [paste both]. Don't rewrite the rulebook. Name the rule that caused the failure, propose the smallest edit, then check it against these approved examples and flag any that would now fail: [paste 2-3].
```

# 🛠️ Tuesday Tool Tip: Hand Muse Wonder your seating-chart puzzle

Seating charts, shift schedules, and carpools all share one shape: a pile of "these two can't be together" rules that gets harder with every name you add. Meta's [launch post](https://research.meta.ai/blog/muse-wonder) shows Muse Wonder building a wedding seating chart from a list of complex matching requirements, which makes it a handy test of whether an agent can juggle many rules at once.

Meta didn't publish the prompt, so here's a version to try:

1. Open Muse Wonder in [Muse Code](https://dev.meta.ai/code), where it's available now. Wonder Full needs a Power or Maximum plan.

2. Paste your guest list, then write each rule as its own numbered line (e.g., "1. Dana and Marcus sit apart," "2. Each table seats 8 max").

3. Use a prompt like the one below, then spot-check a few seats against your rules yourself.

```
Seat these 24 guests at 3 tables of 8. Follow every numbered rule. After the chart, list any rule you could not satisfy and ask me before bending it.
```
Two cautions. Muse Code defaults to a mode that lets Meta train on what you submit, so use first names or switch it off first. And one early reviewer, [per Stork.AI](https://www.stork.ai/blog/metas-new-ai-model-is-brilliantand-already-breaking), hit rate-limit errors within minutes on the paid plans, so don't plan to run this on deadline.

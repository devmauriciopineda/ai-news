Interactive tool maps a fly's brain neurons firing in real time
2,918 Likes
Someone built a Minecraft mod that runs a real fruit fly's entire nervous system inside the game. Not a fake simulation. Actual wiring.
Google Research and HHMI Janelia mapped every neuron in a male fruit fly's brain. The result:
176,422 neurons and 125 million synaptic connections
, all publicly available. This mod plugs that data directly into Minecraft.
Each fly mob runs its own brain on its own thread, in real time. The Minecraft world feeds sensory input in, and real motor neurons decide what the fly does. Two HUD panels show you everything:
Brain view (B key)
: a live map of the whole nervous system, neurons lighting up as they fire
Neuroscope (H key)
: decoded motor commands, firing rates, spike history, and the fly's retina view
Sprint at the fly and its looming-detector neurons trigger an escape jump. Drop sugar near it and the proboscis motor neuron fires. It's the real pathway, not a script.
To try it: drop the jar into
.minecraft/mods/
, run
/fruitfly spawn
, then press B and H. The full connectome is bundled inside.

GPT-6 powered tool lets you mod Super Nintendo games with plain English
2,267 Likes
SuperAstra
lets you modify Super Nintendo games live, while you play them, using plain English prompts. No ROM hacking knowledge needed.
Why is this hard normally? SNES games are raw machine code, basically the lowest-level instructions a computer can run. Getting AI to read and rewrite that in real time is genuinely tough. GPT-6 Astra pulls it off.
Here's what you can actually do with it:
"Whenever Mario gets a coin, shoot 20 fireballs"
"Change the world 1 map to use star world tiles"
"Make your hoe till 10x10 squares when you use it"
"Find my health and keep it full while I'm playing"
To run it, you need
Python 3.10+
, a BizHawk emulator, your own ROM, and an OpenAI API key with access to gpt-6-astra. Launch the companion app, load your ROM, run the Lua script inside BizHawk, then type your prompt and hit Cast.
Changes apply
between frames
while the game keeps running. You can also undo any mutation instantly. It's open source on GitHub under ScottStevenson/SuperAstra.

Meta's autonomous research system places top 10 among 4,000 Kaggle teams
2,225 Likes
Meta just let an AI system enter a real competition against humans, and it held its own.
AIRA3
is an autonomous research agent that can improve other AI models, no human hand-holding required.
Here is what happened: NVIDIA ran a Kaggle challenge where the goal was to make a 30B model smarter at reasoning. Everyone got the same tools. AIRA3 placed
8th out of roughly 4,000 teams
, winning Gold.
How does it actually work? It runs many long-running agents that coordinate asynchronously via a shared forum and filesystem, with no central controller. Think of it like a group chat where AI agents post findings, and others build on top of them. Knowledge compounds over time.
What can it do beyond one competition?
Delivered a
27% latency reduction
on production GPU kernels
Gold-level performance translating 4,000-year-old Akkadian clay tablets into English
The system generalizes across distinct domains by changing only the task specification. Point it at a new problem, same system runs.

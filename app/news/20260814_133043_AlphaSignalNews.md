xAI launches Grok Bot, an AI agent that logs into your tools and works autonomously

xAI just shipped
Grok Bot
, and it is a different kind of AI tool. Not a chatbot. Not a code helper. An AI that logs into your actual accounts and does the work while you sleep.
Here is how it works: each Bot gets its own
cloud computer
, signs into your tools the same way you do, and keeps running after you close your laptop. No API setup needed. It clicks, types, and navigates any browser-based app like a human would.
What can you actually hand off to it?
Keeping a CRM updated automatically
Managing customer support for an online store
Researching accounts and drafting outreach overnight
Negotiating with vendors in your own voice
The big unlock: any tool you can open in a browser is now automatable, no integration required. The catch?
Pricing starts at $120/seat/month
, with no free tier. It is available on macOS, iOS, Windows, and Linux today.

DeepSeek open-sources a plugin-first agent framework under MIT license
15,951 Likes
DeepSeek just dropped
Harness v0.1
, an open-source framework for building AI coding agents, and it's free to use under the
MIT license
, meaning you can build commercial products on top of it with zero restrictions.
The core idea is simple:
everything is a plugin
. Instead of one rigid system, every piece of the agent, including the AI model, tools, memory, file system, and even the UI, is a swappable plugin. You can mix, match, and replace any part without touching the source code.
It ships with four ready-to-use modes:
Standard
: full agent with file editing, shell, web search, and subagents
Code: model writes TypeScript to chain multi-step tool calls together
Minimal: bare-bones shell and file editor, great for benchmarking
Creator: build and test your own custom agent setups
Every session is fully traceable via an append-only log you can replay or fork. To try it: git clone, pnpm install, pnpm dsh web, then open localhost:3080. Expect breaking changes, it's early.

OpenAI launches GPT-5.6 Sol at 750 tokens per second via Cerebras
14,490 Likes
You know the old rule: fast AI = dumb AI. Want the smart model? Wait for it. OpenAI just broke that rule.
Meet
GPT-5.6 Sol Ultrafast
, a new speed tier for their most capable model, powered by Cerebras hardware. Same intelligence, no trade-off.
The numbers:
750 tokens per second
, up to
14x faster
than standard processing. For context, you read at roughly 5-10 tokens per second. This thing is not waiting around.
Why so fast? Normal GPUs constantly shuffle model weights between on-chip and off-chip memory, which creates a bottleneck. Cerebras keeps all 44 GB of weights sitting directly on-chip, so nothing waits. Tokens just flow.
What you can actually build with this:
Real-time voice apps that feel instant
Customer support bots with zero lag
Coding agents that chain dozens of steps in seconds, not minutes
Security and financial tools where delays cost money
Access is limited preview via the OpenAI API right now. You can sign up to be notified when capacity opens up.
